# Peck the Egg – die Eierpeck App

Ein Browserspiel zum österreichischen Osterbrauch Eierpecken: Wirf eine 1-Euro-Münze so auf ein hartgekochtes Osterei, dass sie stecken bleibt.

**Spielen:** https://seppralot.github.io/peck-the-egg/

1. **Zielen:** Die Hand zittert. Tippe, wenn die Münze mittig über dem Ei ist.
2. **Kraft:** Stoppe den Balken im Grünen (ca. 40 % oder 60 %). Bei 50 % ist der Wurf zu fest.

Das Spiel funktioniert offline. Am iPhone in Safari öffnen, dann „Teilen → Zum Home-Bildschirm“.
